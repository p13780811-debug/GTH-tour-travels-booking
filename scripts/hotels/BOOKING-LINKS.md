# GTH PRO Hotel Booking — exact property matching

Customer journey: \`/hotels\` (search/filter) → \`/hotels/stay/{id}\` (original property detail) → **Book Now** (approved hotel-specific affiliate deep link).

**No second hotel search, invented prices, or generic Booking.com fallback.** Photo and accommodation source records remain separately attributed. An OSM entry is not itself a bookable offer.

## What activates Book Now

The \`hotel_booking_links\` table is an additive overlay, keyed by exact OSM source identity or approved owner hotel UUID, plus partner program. No provider search URL is synthesized from hotel names. For each real matched property, a supplier-specific \`provider_property_id\`, property detail URL, and affiliate deep link issued by your approved Travelpayouts program are necessary.

Obtain these only from an authorized supplier property-ID catalog or from the brand's actual matching property page using Travelpayouts → Tools → Links. The classic Hotellook API/widgets/program were discontinued in October 2025: don't use them for new hotel bookings.

## CSV staging: supplier-authorized exact ID matches

Provide \`osm_source_id,provider,provider_property_id,provider_property_url,affiliate_url,hotel_name_at_provider\` as columns. Example schema only; **do not fabricate a hotel or a partner URL**. \`provider\` supports \`klook\`, \`trip_com\`, \`booking_com\` only when the program is actually authorized for the GTH PRO account.

Run after the migration is applied:

\`\`\`bash
python3 scripts/hotels/stage_exact_affiliate_links.py --csv supplied_partner_matches.csv
python3 scripts/hotels/stage_exact_affiliate_links.py --csv supplied_partner_matches.csv --apply
\`\`\`

The importer is dry-run unless \`--apply\` is explicit, is capped at 1,000 records per invocation by default, cross-checks source IDs/name similarity against the real OSM table, uses safe host allowlists and stages **inactive** mappings only. Existing approved entries are never overwritten by the batch importer.

The restricted \`/admin/hotels\` queue requires server-confirmed admin role and two individual confirmations: this supplier ID resolves to the exact hotel property, and the supplied affiliate URL is generated by the account's currently active program. Only then will \`Book Now\` be visible in hotel details. Mappings expire from public reads after 180 days if not reverified.

## Coverage

If you have 21,516 OSM hotel records and zero affiliate provider property IDs/approved deep links, the catalog remains navigable and hotel pages remain available, but **zero direct bookings can be honestly activated**. This cannot be fixed by constructing guessed URLs from names/coordinates, and is not a deployment bug.

Photo enrichment: source images / licensed Wikimedia Commons as separate overlays; the optional Google Places on-demand feature requires an enabled approved API key and usage budget. Do not copy Google images to Supabase, invent hotel photographs, or label stock interiors as real property photos.

No production deployment, data mutation, or secret exposure is part of this code change.
